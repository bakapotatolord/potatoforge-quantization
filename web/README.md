# PotatoForge Command UI

The Command UI is PotatoForge's local React frontend. It provides forms for
Inspect, Audit, Optimize, Quantize, and library settings; the FastAPI backend
continues to perform validation and execute the underlying PotatoForge commands.

## Development

Install frontend dependencies from the repository root:

```powershell
pnpm --dir web install
```

Start the frontend development server:

```powershell
pnpm --dir web run dev
```

Vite serves the UI at `http://127.0.0.1:5173` and proxies `/api` requests to
the local API at `http://127.0.0.1:8000`. Start that API separately from the
repository root:

```powershell
.\.venv\Scripts\python.exe -m uvicorn potatoforge.server.app:app --host 127.0.0.1 --port 8000 --reload
```

## Build and launch

Create the static bundle used by the local UI command:

```powershell
pnpm --dir web run build
uv run potatoforge ui
```

The production bundle is written to `web/dist` and served locally by
`potatoforge ui`; it is not a separately deployed web application.

## Checks

```powershell
pnpm --dir web run lint
pnpm --dir web run build
```

`src/routeTree.gen.ts` is generated by TanStack Router. Do not edit it by hand;
run the frontend build after adding or renaming a route.
